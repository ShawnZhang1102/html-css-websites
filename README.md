# HTML & CSS Websites

> Class Project · CSC 170, University of Rochester

A collection of multi-page websites built while learning HTML and CSS — from a first single page to a multi-topic PHP site.

## What It Includes

- **project1**: a tribute site (Audrey Hepburn).
- **project2**: a second multi-page site.
- **project3**: a multi-topic site (Audrey Hepburn, Dwayne Johnson, Tesla, Zelda) with CSS, JavaScript, and a slider library.
- **pro3**: a Marilyn Monroe site.
- **labs 02–10**: weekly lab sites, including the Marilyn Monroe lab series (lab04–lab08) and a contact-form lab (lab09).
- **csc-170/**: lab02 and lab03 from the course folder.

## Tech Stack

HTML · CSS · JavaScript · PHP (project3 and lab10)

## How to Run

- **Static sites** (most folders): open any `index.html` or `start.html` in a browser.
- **PHP sites** (`171/project3`, `171/lab10`): they need a PHP server, e.g.:

```bash
cd 171/project3
php -S localhost:8000
```

## Files

- `171/` — projects (`project1`, `project2`, `project3`, `pro3`), labs (`lab04`–`lab10`), and a starter page.
- `csc-170/` — `lab02` and `lab03`.
